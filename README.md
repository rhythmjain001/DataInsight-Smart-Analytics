 📊 DataInsight – Smart Data Analytics Platform
**DataInsight** is a Python-based data analytics platform built using Streamlit. It helps users upload business datasets, clean data, analyze information, create visualizations, generate business insights, run SQL queries, and forecast future sales.

🚀 Features
- **Dashboard:** View dataset overview and key statistics.
- **Data Cleaning:** Handle missing values and duplicate records.
- **Data Analysis:** Calculate mean, median, minimum, and maximum values.
- **Data Visualization:** Create interactive charts and graphs.
- **Automatic Insights:** Get useful summaries about your dataset.
- **Business Analytics:** Calculate revenue and product performance.
- **Smart Business Insights:** Identify top-performing products and business trends.
- **SQL Analytics:** Execute SQL queries using DuckDB.
- **Business KPI Dashboard:** Monitor important business performance indicators.
- **Sales Forecasting:** Estimate future revenue using Exponential Smoothing.
- **PDF Reports:** Generate downloadable analytics reports.

🛠️ Technologies Used

⚙️ Installation and Setup
1. Clone the repository**
```bash
git clone https://github.com/rhythmjain001/DataInsight-Smart-Analytics.git
```
2. Open the project folder**
```bash
cd DataInsight-Smart-Analytics
```
3. Create a virtual environment**
```bash
python -m venv venv
```
4. Activate the environment (Windows)**
```bash
venv\Scripts\activate
```
5. Install dependencies**
```bash
pip install -r requirements.txt
```
6. Run the application**
```bash
python -m streamlit run app.py
```
The application will open in your browser at `http://localhost:8501`.
